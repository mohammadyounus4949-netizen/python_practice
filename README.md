# Data Cleaning Project using Python

## Project Overview

This project demonstrates how to clean raw CSV data using Python and Pandas. It includes handling missing values, removing duplicate records, formatting columns, and exporting clean data.

---

## Features

- Read CSV files
- Handle missing values
- Remove duplicate rows
- Rename columns
- Format data
- Export cleaned dataset
- Beginner-friendly code

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/data-cleaning-project.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python src/clean_data.py
```
